# Experiment 9: Extract SMS and Contacts Using Sleuth Kit

## Aim
To examine a mobile device forensic image and extract SMS messages and contact information using Sleuth Kit, where the data is available.

## Tool Used
- Sleuth Kit

## Procedure
1. Open a terminal in a supported forensic Linux environment.
2. Identify the authorized mobile forensic image.
3. Use Sleuth Kit tools to examine the image and identify its file system.
4. Locate the relevant files or database containing SMS messages and contacts.
5. Examine the file metadata and extract the relevant files, if available.
6. Analyze the extracted data using an appropriate database viewer or parser, if required.
7. Save the extracted results securely and document the findings.
